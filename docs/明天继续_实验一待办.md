### 今天踩过的两个坑（明天别再花时间）

1. **一开始 MC02 只接了 DAPLink 的 3.3 V**，`vbat=3369mV`，CAN 收发器没工作 → 满屏 bus-off。
   → 24 V 必须接到 MC02 的电源输入。
2. **CAN_H / CAN_L 接错（或没接好）**，寄存器报 `LEC=5 (Bit0 error)` + `REC=0`
   —— 这个组合表示"**MC02 自己发的显性电平都没读回来**"，是 MC02 侧的问题，不是对端。
   重新接线后立刻正常。**记住这个判据**：
   - `LEC=3 (Ack error)` → 对端问题（C620 没电 / 接反 / 断线）
   - `LEC=5 (Bit0)` → 本端收发器/总线短路问题

### 第 3 步：跑实验一

**开始录数据**（另开一个终端，别用串口助手）：

```powershell
python tools\power_bench_log.py -p COM33 -o noload.csv
```

> 这个脚本会把纯数字行写进 CSV，同时把板子的日志（含"第几档"提示）打在你屏幕上，
> 所以你能看到 `[bench] step 3/16 Icmd=1100 ... (now is the time to read the meter)`。

**按 PA15 开始**（只按一次；中途再按 = 急停）。全程约 **2 分 44 秒**：

| 时间(s，从按键算) | Icmd | | 时间(s) | Icmd |
|---|---|---|---|---|
| 0~2 | 0（准备） | | 82~92 | 2500 |
| 2~12 | 500 | | 92~102 | 2250 |
| 12~22 | 800 | | 102~112 | 2000 |
| 22~32 | 1100 | | 112~122 | 1700 |
| 32~42 | 1400 | | 122~132 | 1400 |
| 42~52 | 1700 | | 132~142 | 1100 |
| 52~62 | 2000 | | 142~152 | 800 |
| 62~72 | 2250 | | 152~162 | 500 |
| 72~82 | 2500 | | 162~164 | 0 |

指示灯：白（待机）→ 按 → **蓝**（2 秒准备）→ **绿**（逐档给电流）→ 结束回白。
急停/保护 → **红**。

⚠ 轮子悬空，但**电机座要夹紧**（2500 counts 的扭矩足够让整台电机跳起来）。

### 第 4 步：分析

**没有电流表也能先做（"体检"）**：

```powershell
python tools\power_bench_fit.py noload.csv
```

会打印每档的 `Icmd / given / rpm / vbat / temp`，以及：
起转死区大概多少 counts、最高转速、最高温度。

**有电流读数才能拟合 `k1`/`a`** —— 每档读一个电流值，写成 `manual.csv`：

```csv
seg,I_A
0,0.42
1,0.66
...
15,0.41
```

（`seg` 就是日志里的 `step`，从 0 开始；16 段 = 上升 8 段 + 下降 8 段。
上升段电流一样但摩擦不同，两段都记；只记上升段也能拟合。）

```powershell
python tools\power_bench_fit.py noload.csv --manual manual.csv
```

判据：`k1` 在 0.5e-7 ~ 3e-7（参考 1.23e-7），`a` 在 2~8 W，R² > 0.90。
拟合结果填回 `modules/power_control/power_control.c` 的默认 `k1` / `a`。

> 拿电流读数的三种办法（按成本）：
> 1. 万用表 DC 10A 档串在 `24V+ → C620+` 之间（最便宜，每档读一次）；
> 2. 带电流显示的直流电源；
> 3. INA226/功率计模块（全自动，但 MC02 的 I2C 没引到排针，要飞线）。
> 拿到传感器后把读数接到 `PowerBenchSetPinHook()`，CSV 的 `pin_mw` 列就有值，
> 拟合脚本会自动用它，流程一行都不用改。

## 三、常见现象对照（明天真出问题先看这个）

| 现象 | 原因 | 处理 |
|---|---|---|
| 只听到"滴"、没有三音 | 启动卡在调度器之前 | 串口会打 FAULT DUMP，按 [崩溃排查与中断规范.md](崩溃排查与中断规范.md) 读 |
| 完全没声音/没灯 | 没上电 / 固件没烧进去 | 查 24 V、重新烧录 |
| 满屏 `bus-off` / `TX fifo full` | CAN 不通（看下面三条） | —— |
| `[bench] no feedback from C620` | CAN 没通 | ① C620 有没有电 ② CAN_H/L 有没有接反 ③ 共地 ④ 120 Ω 终端 |
| 按键后轮子不转，但 `given` 不涨 | 电流低于启动死区 | 把 `power_bench.c` 的 `k_default_steps[0]` 从 500 提到 800 |
| 按了没反应 | 按键要按住 ~0.4 s 消抖 | 按一下等一下 |
| 串口全是乱码 | 波特率不对 | 115200-8N1 |
