# 步兵接线：按「层 + 总线」重组

> 原图画的是「线怎么走」，这张图回答的是「谁挂在哪条线上、电从哪来」。
> 配图：`接线_两张图.png`（一张只讲电源，一张只讲 CAN）

## 三层结构

```
① 云台层（随 Yaw 转）      主控、云台电机、摩擦轮、视觉
        ↕  导电滑环 12 路 5A（用 10 芯 / 5 组）
③ 底盘层（不随 Yaw 转）    电池、电管、底盘电机、裁判系统
```

滑环把「会转的云台」和「不转的底盘」之间所有电气连接收拢成 5 组线。

## 一、电源：一条主干 + 三次分配

```
电池 24V (XT60)
   │
 电管（功率分配）
   ├─ Chassis XT30 ──► 底盘分电板 ──► 4× 3508+C620
   │                              └─► 转接板 ──► MG4005
   ├─ Gimbal XT30 ───► [滑环 ⑤] ──► 云台分电板 ──► 2× 4310（大P/小P）
   │                                        └─► MC02 / 稳压模块 ──► 小电脑
   │
   ├─ 超电功率板 ──► 电容管理模块 ──► 超级电容组
   ├─ 裁判系统主控 ──► 场地交互模块 / 灯条 / 小装甲 / 测速模块
   └─ 网关 C 板（只取电，作用是把裁判串口转成 CAN）
```

**云台分电板不做升降压**，只做二次分配。小电脑的电压由**稳压模块**单独给（DC 圆口转 XT30/60）。

## 三、滑环 5 组分配

| 组 | 内容 | 供给 | 线径 |
|---|---|---|---|
| ⑤ | 24V + GND | 云台电机（2×4310） | — |
| ③ | 24V + GND（滤波后） | MC02 / 稳压模块 | — |
| ② | 24V + GND | 发射机构（摩擦轮） | — |
| ④ | CAN_H / CAN_L | 四芯屏蔽 | — |
| ① | CAN_H / CAN_L | 两芯 | — |

滑环标注 **12 路 5A**，实际用 10 芯（5 组 × 2 芯）。

## 四、五个要留意的地方

### 1. 滑环每路只有 5A，是整车的瓶颈

2 个 4310 同时堵转的峰值电流远超 5A。**滑环 ⑤ 是这条链上最窄的一段** —— 要么限流，要么两芯并联。

### 2. 短路电流会流过滑环

如果云台侧发生反接/短路，几百安的故障电流要经过滑环的 5A 刷丝。**刷丝烧蚀后不会立刻失效**，表现为接触电阻变大、电压跌落、偶发掉线 —— 很容易误判成"板子坏了"。

建议：滑环前后各加一路保险/自恢复保险丝。

### 3. 地盘 CAN 与云台 CAN 的终端电阻

两条总线各自两端 120Ω。跨滑环的那条，**终端电阻要放在滑环两端的外侧**（滑环本身有接触电阻，不能当节点）。图上原注释也提醒了"CAN 线星形连接"问题。

### 4. 三条 24V 分开走是对的

⑤ / ③ / ② 分三组，好处是**电机堵转时不会把主控的电压拉塌**。这点设计得对，别为了省滑环把三组并成一组。

### 5. 电管到云台的距离最长

Gimbal XT30 过滑环到云台分电板，这段线阻最大。**线径要按 10A 选**，不要按平均 3A。
