# 怎么拟合 k1、k2、a

## 一、先明确要拟合什么

模型（部署形式）：

```
Pin = CT·I·ω + k1·ω² + k2·I² + a
```

| 符号 | 含义 | 单位 | 已知/未知 |
|---|---|---|---|
| `Pin` | 电调输入功率（INA226 实测） | W | 实测 |
| `I` | 力矩电流指令 `Icmd` | counts | 自己发的 |
| `ω` | 转子转速 | rpm | C620 反馈 |
| `CT` | `1.9969e-6` | W/(rpm·count) | 已知（KT/9.55×20/16384） |
| `k1` | 铁损+风阻+搅油系数 | W/rpm² | **待拟合** |
| `k2` | 铜损系数 | W/count² | **待拟合** |
| `a` | 静态损耗 | W | **待拟合** |

把已知项挪到左边：

```
y = Pin − CT·I·ω = k1·ω² + k2·I² + a
```

**左边是"损耗"，右边是三项。** 拟合就是找三个系数，让右边尽量贴近左边。

---

## 二、为什么不直接一次拟合三个？

因为 `ω²` 和 `I²` 会**共线**：空载时电流越大转速越高，两个变量同向变化，最小二乘分不清"这瓦是转速带来的还是电流带来的"，解出来的 k1 可能是负的（工程里 `constantspeed.csv` 拟合出 k2=5.5e-6 就是这个病）。

所以分两步，每次只让**一个变量变化**：

| 步骤 | 实验 | 让谁变 | 谁几乎不变 | 拟合 |
|---|---|---|---|---|
| 1 | 空载扫转速 | ω | I 很小 | `y = k1ω² + a` |
| 2 | 堵转扫电流 | I | ω≈0 | `y = k2I² + a` |

---

## 三、实验一：拟合 k1 和 a

### 数据处理

1. 丢掉前 2 秒（上电、CAN 还没稳）；
2. 只保留**准稳态**点：`|dω/dt| < 500 rpm/s`、`|ω| > 50`、`|I| > 100`；
3. 逐点算 `y = Pin − CT·I·ω`，`x = ω²`。

### 最小二乘（一元线性回归）

```
x̄ = mean(x),  ȳ = mean(y)
k1 = Σ(xi−x̄)(yi−ȳ) / Σ(xi−x̄)²
a  = ȳ − k1·x̄
```

评价：

```
R²   = 1 − Σ(yi−ŷi)² / Σ(yi−ȳ)²
RMSE = sqrt( mean( (yi−ŷi)² ) )
```

### 判据

- `k1` 在 **0.8e-7 ~ 3e-7** 之间（M3508 参考 1.2e-7）；
- `a` 在 **2 ~ 8 W**；
- `R² > 0.95`，`RMSE < 1 W`；
- 换一组转速数据重拟合，`k1` 变化 < 30%。

### 用 Excel 也行

| 列 | 公式 |
|---|---|
| A：Icmd | 原始 |
| B：ω | 原始 |
| C：Pin | `bus_mv*bus_ma/1000000` |
| D：Pm | `=1.9969e-6*A2*B2` |
| E：y | `=C2-D2` |
| F：x | `=B2^2` |

选中 E、F 两列 → 插入散点图 → 右键数据点 → 添加趋势线 → 线性 → 显示公式。
公式形如 `y = 1.23E-07x + 4.08`，**斜率就是 k1，截距就是 a**。

## 四、实验二：拟合 k2

### 数据处理

1. 只保留 `|ω| < 80 rpm`、`|I| > 300` 的点（堵转）；
2. 每一步电流**跳过前 0.3 秒**（电流环建立、机械回弹）；
3. `x = I²`，`y = Pin − a`（a 用实验一的结果）。

### 回归

和上面一模一样的公式，只是 `x` 换成 `I²`：

```
k2 = Σ(xi−x̄)(yi−ȳ) / Σ(xi−x̄)²
```

### 判据

- `k2` 在 **1.0e-7 ~ 2.0e-7**（参考 1.45e-7）；
- 反推相电阻 `R ≈ k2 / 2.2e-6`，和手册同量级（M3508 是几十 mΩ）；
- `R² > 0.98`。

---

## 五、迭代一次，把两个实验缝起来

空载拟合时 `k2·I²` 被忽略了，所以 k1 会**偏大一点点**。拿到 k2 后修正一次：

```
1) k2 = 0，用空载数据拟合 → k1⁰, a⁰
2) 用堵转数据、固定 a⁰ 拟合 → k2
3) 重新算 y' = Pin − CT·I·ω − k2·I²，再拟合 → k1¹, a¹
4) 用 k1¹、k2、a¹ 预测两组数据，看残差是否 < 1.5 W
```

一般迭代一次就收敛，k1 会下降 5~15%。

## 六、脚本怎么用

```bash
# 实验一（带表头的 CSV）
python host/fit_params.py noload.csv --mode noload

# 实验二
python host/fit_params.py stall.csv --mode stall --a 4.08

# 两个一起，做联合校验
python host/fit_params.py noload.csv --mode noload --stall stall.csv --k2 1.45e-7
```

输出：

```
[空载：Pin - Pm = k1·ω² + a]  n=8421
  k = 1.231e-07   (W/rpm²)
  a = 4.082 W
  R² = 0.9831   RMSE = 0.42 W
```

并生成 `fit_result.png`：左边散点+拟合线，右边残差图。**残差图必须是"随机分布在 0 附近"**，如果有明显弯钩，说明模型少了项（比如 `ω` 一次项）。

`--format vofa` 可以直接吃 VOFA+ 导出的 4 列文本（`Icmd,rpm,Pin_mW,bus_mv`）。

## 七、常见错误对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| k1 为负 | 转速范围太窄；或 `Pin` 没减 `Pm` | 加宽转速；检查公式符号 |
| R² 只有 0.3 | 数据里全是瞬态 | 按 `|dω/dt|` 过滤 |
| k2 大 10 倍 | 电流列不是 counts，是安培 | 统一用 counts |
| a 是负数 | 电压没校准 / 采样电阻值填错 | 万用表对一下 INA226 |
| 残差随转速单调上升 | 母线电压在掉，没记录 | 记录 V，按 `V/24` 归一化 |
| 同一台电机两次 k1 差很多 | 温度不同（R 漂） | 冷机测，或记录温度做补偿 |
| 堵转数据温度爆表 | 脉冲太长 | 1~2 s 脉冲，间隔 15 s |

## 八、拟合完贴到哪里

```c
/* 你拟合出来的值 */
#define K1_W2   1.231e-7f   /* 乘 ω²  */
#define K2_I2   1.453e-7f   /* 乘 Icmd² */
#define A_STATIC 4.081f

static inline float motor_power(float w, float i)
{
    return 1.99688994e-6f * i * w + K1_W2 * w * w + K2_I2 * i * i + A_STATIC;
}
```

⚠️ 注意别学原工程把 k1/k2 挂反——`k1` 乘 `ω²`，`k2` 乘 `I²`。
