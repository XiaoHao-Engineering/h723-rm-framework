# VOFA+ 接线与配置（达妙 MC02）

## 一、接哪根线

### 方案 A：USB-TTL 接 USART1（推荐，最稳）

```
MC02                          USB-TTL 模块
PA9  (USART1_TX) ───────────► RX
PA10 (USART1_RX) ◄─────────── TX
GND             ───────────── GND
（VCC 不要接！MC02 自己供电）
```

- 波特率 **921600**，8N1；
- USB-TTL 的电平跳线选 **3.3 V**（H7 的 IO 不耐 5 V）；
- 只接 TX/RX/GND 三根，千万别把 5V 灌进板子。

> MC02 的 USART1 在 PD0/PD1 旁边那组排针上，丝印一般写 `TX1/RX1` 或 `PA9/PA10`。
> 如果找不到，用万用表通断档从 MCU 引脚量到排针。

### 方案 B：MC02 自带 USB（虚拟串口）

```
MC02 USB-C ──── 电脑 USB
```

- 固件里要开 **USB Device (CDC)**，CubeMX 选 `USB_OTG_HS` + `Communication Device Class`；
- PA11 = DM，PA12 = DP（板载已有）；
- 电脑上会出现一个新的 COM 口，VOFA+ 直接选它，**波特率随便填**（CDC 不受波特率影响）；
- 优点：不用转接板；缺点：CubeMX 要配 48 MHz 时钟和描述符，第一次弄容易卡住。

### 方案 C：USART10（PE2/PE3）

板子上的调试串口，默认 115200，也可以用来接 VOFA+，但速率低，200 Hz × 4 通道会有点吃力。

### CAN 是另一路，别混

```
C620 CAN_H ── MC02 FDCAN1_H (PD1)
C620 CAN_L ── MC02 FDCAN1_L (PD0)
CAN 两端各 120 Ω（短线一端也行）
```

串口只管"看波形"，CAN 只管"控电机"，两者独立。

## 二、VOFA+ 配置

1. 打开 VOFA+ → 左下「数据引擎」→ 选 **串口** → 端口选 `COMx` → 波特率 `921600` → **打开**；
2. 协议选 **FireWater**（文本，最直观）；
3. 右侧拖一个「波形图」控件；
4. 代码默认发 4 个通道，顺序是：

   | 通道 | 含义 | 单位 |
   |---|---|---|
   | ch0 | `Icmd` 力矩电流指令 | counts |
   | ch1 | `rpm` 转子转速 | rpm |
   | ch2 | `Pin` 输入功率 | **mW**（除以 1000 就是 W） |
   | ch3 | `bus_mv` 母线电压 | mV |

5. 采样率填 **200**（对应代码里 `log_period_ms = 5`）；
6. 点「开始」，手转一下轮子，ch1 应该有反应——先确认链路通，再上电跑实验。

> 想要更稳、更高频，把 `PT_LOG_MODE` 改成 `2`（JustFloat），VOFA+ 协议也选 JustFloat，通道数填 4。
> 想存 CSV 给拟合脚本，改成 `0`（带表头），用串口助手存文件。

## 三、看到什么算正常

| 阶段 | 现象 |
|---|---|
| 上电 0~2 s | ch0 = 0，ch1 = 0，ch2 ≈ 几瓦（电调待机） |
| 爬升段 | ch0 线性上升，ch1 跟着上升，ch2 上升 |
| 到顶保持 | ch0 恒定，ch1 稳定在某个转速（摩擦平衡） |
| 结束 | ch0 回 0，ch1 缓慢降速 |

ch2 在爬升初期可能只有 2~5 W，随着转速上升涨到 15~30 W——这就是 `k1ω²` 在起作用。

## 四、常见问题

| 现象 | 原因 |
|---|---|
| VOFA 一片空白 | 协议选错（应该 FireWater）；或 TX/RX 没交叉 |
| 全是乱码 | 波特率不是 921600；或 USB-TTL 电平是 5 V |
| 只有一行就不动了 | 固件里 `pt_start()` 没调用，或 TIM6 没启动 |
| 波形抖得厉害 | 采样率填错；或 INA226 的 I2C 被其他任务打断 |
| ch0 有、ch1 没 | CAN 没收到 0x201：检查 C620 ID、终端电阻 |
| ch2 一直是 0 | INA226 没初始化成功：查 I2C 地址（0x40）、采样电阻值 |
| 功率是负的 | 采样电阻接反了，交换 INA226 的 IN+/IN− |
