# 发射机构（shoot）

摩擦轮 + 拨弹盘（达妙 DM4310，挂在 **CAN3**，ID = `LOADER_CAN_ID`，默认 4）。
单发角度控制已经**并入本模块**（不再单独建 `loader_angle` 模块），这样只注册一次电机，
不会和 `ShootInit()` 抢同一个 ID。

## 1. 文件

| 文件 | 作用 |
|---|---|
| `shoot/shoot.c` | 摩擦轮、拨弹盘上电时序、卡弹保护、**右上拨杆单发** |
| `shoot/shoot.h` | `ShootInit()` / `ShootTask()` |
| `shoot/shoot.md` | 本文件 |
| `shoot/loader_heat.c/h` + `shoot/loader_heat.md` | **热量管理**：状态机估计 + 前馈规划 + 硬限幅（含 VOFA 通道表） |

装配在 `rm_example/rm_app.c` 里：`RMAppInit()` 调 `ShootInit()`，`RMAppTask()` 调 `ShootTask()`。

## 2. 拨杆映射

| 拨杆 | 位置 | 行为 |
|---|---|---|
| **S1（左）** | 上 | 发射总开关打开（cmd 发布 `SHOOT_ON`） |
| | 中 / 下 | 停 / 急停（`SHOOT_OFF`）→ **任何模式都停机，优先级最高** |
| **S2（右）** | **上** | **单发**：每“拨到上”一次，拨盘推进 `LOADER_ANGLE_DEG`（35°），然后停 |
| | 中 / 下 | 走原有 `shoot_cmd` 逻辑（连发 / 逐发 / 停） |

- 单发只认**上升沿**：一直按住“上”不会连发；必须**手动拨回中位再拨上**才是下一发。
- S2 上 → 中 之间不会重新初始化电机（不切控制模式），响应没有额外延迟。
- 急停（S1 中/下）会覆盖单发：单发过程中拨下去也会立刻停。

## 3. 参数（`rm_config.h`）

| 宏 | 默认 | 说明 |
|---|---|---|
| `FRICTION_L_ID` / `FRICTION_R_ID` | **3 / 4** | 摩擦轮电调 ID（避开达妙 0x201） |
| `LOADER_RX_ID` | **0** | 达妙反馈帧 = Master ID |
| `LOADER_CAN_ID` | **1** | 电机 CAN ID（当前用电机的**出厂默认 1**；必须和电机内部一致） |
| `LOADER_ANGLE_DEG` | **30°** | 每发推进角度 = **一个齿距**（360/12）。不要多给，否则相位每发累积 |
| `LOADER_ANGLE_RPM_FAST` | 80 | 前段推进转速（输出轴 rpm） |
| `LOADER_ANGLE_RPM_SLOW` | 25 | 接近目标时降速，减小惯性超调 |
| `LOADER_ANGLE_SLOW_ZONE_DEG` | 8° | 距目标多少度开始降速 |
| `LOADER_ANGLE_STOP_MARGIN_DEG` | 5° | 提前这么多度就停，抵消减速惯性 |
| `LOADER_ANGLE_TIMEOUT_MS` | 1000 | 一发超时，判卡弹 |
| `LOADER_DIR` | 1 | 方向反了改 `-1` |

## 4. 实现要点

1. **复用 `ShootInit()` 注册的电机**：单发逻辑直接用 `loader` 实例，不重复 `DMMotorInit`；
2. **速度模式 + 角度积分**：用实测 `position_deg` 累计转过的角度，到
   `35° - 5°` 就下发 0 转速，剩余 5° 由惯性补上（比位置模式更适合连续旋转的拨盘）；
3. **单发不走斜坡**：正常连发有 `LOADER_ACC_RPM_S` 斜坡，单发若走斜坡会多转 30°+，所以单发直接下发；
4. **单发超时**：1 秒内没转够 35° → 本发放弃（`loader_shot_busy=0`），
   交给下面的卡弹保护处理；拨回中位后可再打。


## 4.1 卡弹 / 扭矩保护（赛场不失效策略）

> 目标：**卡弹不能导致电机失能**，要靠机械动作自己脱困。

| 情况 | 动作 |
|---|---|
| 单次卡弹（速度没跟上 + 扭矩顶住，持续 `LOADER_JAM_MS`） | 停 → **反转退弹** `LOADER_REVERSE_RPM` / `LOADER_REVERSE_MS` → 停 → 继续 |
| **短时间连续 3 次卡弹** | 停 → **回拨 `LOADER_BACKOFF_DEG`（默认 60°）** → 停 → **计数清零** → 继续 |
| 之后又连续 3 次 | 再次回拨 60°，**循环往复，永不失能** |
| **扭矩超限**（`>= LOADER_TQ_MAX` 持续 `LOADER_TQ_HOLD_MS`） | **不管是否在卡弹状态**，立即在**当前旋转方向的反方向**退让一次（不计入卡弹次数） |

参数（`rm_config.h`）：

| 宏 | 默认 | 说明 |
|---|---|---|
| `LOADER_RETRY_MAX` | 3 | 连续第几次开始回拨大角度 |
| `LOADER_BACKOFF_DEG` | 60° | 回拨角度 |
| `LOADER_BACKOFF_RPM` | 30 | 回拨转速（输出轴 rpm） |
| `LOADER_BACKOFF_TIMEOUT_MS` | 1500 | 回拨超时（防卡死等） |
| `LOADER_JAM_CLEAR_MS` | 3000 | 正常运行这么久就把“连续次数”清零（只统计短时间连续） |
| `LOADER_JAM_TQ` | 1.2 N·m | 判卡弹的扭矩门限 |
| `LOADER_TQ_MAX` | 1.6 N·m | 扭矩硬门限（触发反向退让） |
| `LOADER_JAM_MS` / `LOADER_TQ_HOLD_MS` | 300 / 100 ms | 持续多久才动作 |

**唯一还会失能的入口**：遥控急停（S1 中/下 → `SHOOT_OFF`）。这是安全档，不属于卡弹保护。

日志：

```
[shoot] jam detected, retry 1/3, reverse
[shoot] jam detected, retry 2/3, reverse
[shoot] jam x3 -> backoff 60 deg (never disable)
[shoot] backoff done, 61 deg
[shoot] torque over limit 1.83 Nm, reverse
```

## 5. 为什么不用位置模式

达妙位置模式的目标范围是 **±PMAX（默认 12.5 rad ≈ ±716°）**。
本车拨盘连续旋转、不回中，每发累加 35° 时约 **20 发**就会撞到范围上限报错。
所以单发用“速度 + 角度积分”；如果机构是“打完会回中”，可以改成位置模式。

## 6. 调试

上电日志：

```
[dm_motor] motor id [1] mode [3] registered     ← 注册成功(3=速度模式)
[shoot] loader mode -> VEL(3), OC=14%
[shoot] loader enabled, ready
```

单发日志：

```
[shoot] single shot #1 from 12.3 deg
```

常见问题：

| 现象 | 处理 |
|---|---|
| 拨到上没反应 | 看 S1 是否在上（总开关）；看日志 `loader enabled` |
| 方向反了 | `LOADER_DIR` 改 `-1` |
| 一次转两发 | `LOADER_ANGLE_DEG` 减到 30°；或检查枪口单发限位间隙 |
| 打不出弹/空发 | `LOADER_ANGLE_DEG` 加到 38~40° 试 |
| 一发报 timeout | 卡住或电流不够：查 `LOADER_OC`、机械卡滞 |
| 电机不动 | 确认电机内部 CAN ID = `LOADER_CAN_ID`（见 `docs/达妙电机ID设置.md`） |

## 7. 单发角度怎么定（双发 / 空发问题）

12 齿 → 齿距 30°。**单发必须正好走一个齿距**，不能多给。

### 为什么不能用 35°

| 每发角度 | 后果 |
|---|---|
| **30°（齿距）** | 每发都对齐同一齿位，相位不累积 ✓ |
| 35° | 每发多走 5°，**相位每发累积 5°**；6 发后偏 30°（整整一个齿） |

偏了一个齿之后：
- 某一发的“起点”正好落在平时的“终点”上 → 一次行程里会多带过一个齿 → **双发**；
- 或者行程停止在“齿还没完全把弹推过限位”的位置 → **空发**。

所以**双发和空发其实来自同一个原因：累积相位漂移**，不是 35° 本身“太大”。

### 现在怎么做的

1. **每发 30°**（一个齿距）；
2. **两段速度**：离目标 > 8° 时 80 rpm，最后 8° 降到 25 rpm，
   把惯性超调压到 1~2°（超调也会累积，必须压住）；
3. **每发打印实测角度**：

```
[shoot] shot done, 30.4 deg (target 30)
```

如果长期看到 `28.x` / `31.x` 这种，说明机构有打滑或限位顶住，需要查机械；
如果偶尔 `shot timeout`，说明这一发被卡住（会走卡弹保护）。

### 如果 30° 仍然偶尔双发/空发

说明你的**枪口限位间隙不是严格的“一个齿距”**，这时要做“齿位对齐”：
每发的目标不是“当前位置 + 30°”，而是“**下一个 30° 整数倍的绝对齿位**”，
这样无论超调多少都不会累积。需要一次手动校准（把拨盘转到一个弹刚好的位置，
记为 0 齿位）。需要的话我可以加这个模式（参数 `LOADER_TOOTH_ALIGN_ENABLE`）。

## 8. 位置反馈量程 ±PMAX（重要）

手册第 12 页：反馈帧的 `POS` 是 **16 位**，按图 2 线性映射到 **±PMAX**（默认 **±12.5 rad ≈ ±716°**）。
它不是机械限位，也**不会报错**（错误码表里没有"位置越界"），但超过后读数会**绕回**。

| 模式 | 超过 ±PMAX 的后果 |
|---|---|
| 位置模式 | 目标不得超出 ±PMAX；超出后误差计算失效，可能停在边界或反向乱转 |
| 速度模式 | 电机照转，但**位置读数绕回**，靠读数算角度的算法会错 |

所以本车的策略是：

1. **单发/回拨全部用“软件累计角度”** `loader_pos_total_deg`：
   每 10ms 取一次位置，按最短路径（±180°）累加成不回绕的总角度；
2. 这样一个齿距 30° 的增量永远算得对，**连续打几百发也不会受 ±716° 影响**
   （100Hz 采样下，80 rpm = 480°/s 每周期才 4.8°，远小于 180°，不会误判）；
3. 位置模式只在"目标绝对不超出 ±PMAX"的场合才可用，例如每次回中的推弹机构。
